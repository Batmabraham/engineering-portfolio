# Industrial Pipe-Support Frame

**Status:** In progress — geometry, loads, and requirements are being defined. No structural calculations, verified results, or final member selections have been completed.

## Problem

Develop a conceptual two-column structure supporting an elevated horizontal pipe. Investigate how the structural arrangement affects vertical load capacity, lateral deformation, and material use.

## Design direction

The selected baseline is a two-column frame with a horizontal beam. The project will examine combined vertical and lateral performance and compare the baseline with diagonal bracing. Inclined struts providing an intermediate beam support may also be investigated; that alternative has not been selected.

The application connects civil structural analysis with industrial facilities. It does not claim nuclear qualification.

## Planned analysis

1. Define the pipe, contents, supported length, load transfer, and required clearance.
2. Establish justified vertical and horizontal load cases and performance limits.
3. Define connections, supports, member properties, and modeling assumptions.
4. Develop hand calculations and a spreadsheet or MATLAB model.
5. Check the model against suitable reference cases and equilibrium.
6. Compare alternatives, revise the design, and document the tradeoffs.

The computational tool has not yet been selected. Reproduction instructions will be added when a model exists.

## Planned deliverables

Design documentation, calculation files, drawings, comparison figures, and a six-minute presentation. The course presentation is due November 8, 2026; presentations begin November 9.

## Scope and limitations

This is a conceptual educational study. Detailed connections, foundations, thermal behavior, dynamic response, and nuclear seismic qualification are not currently included. The treatment of out-of-plane stability must be stated explicitly before interpreting a two-dimensional analysis as evidence of overall structural stability.
